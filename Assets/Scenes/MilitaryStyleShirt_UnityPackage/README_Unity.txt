Unity import instructions
=========================
1. Extract this ZIP.
2. Drag MilitaryStyleShirt.obj and MilitaryStyleShirt.mtl into your Unity Assets folder.
3. Select the OBJ in Unity and set Scale Factor to 1.
4. Drag MilitaryStyleShirt into the Scene.
5. If materials do not link automatically, assign the imported materials manually.

This is a simplified low-poly blockout based on the reference image. It includes:
- khaki shirt body
- sleeves and cuffs
- collar
- two chest pockets and flaps
- front buttons
- simple neck and display stand

For a more realistic result, open the OBJ in Blender and refine the cloth shape, seams, folds, and topology.
